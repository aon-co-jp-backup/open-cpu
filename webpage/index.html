open-cpu

概要 / Overview

`aon-co-jp`エコシステム共通の、CPU命令セット検出・ランタイムディスパッチライブラリ(Rust)。AVX2・AVX-512・PCLMULQDQ・BMI2・FMA3などを実行時に検出し、RAID・DB・AI推論の各プロジェクトで共有します。配布物はお使いのCPUの対応状況を調べる診断ツールです。

The shared CPU instruction-set detection and runtime-dispatch library (Rust) of the aon-co-jp ecosystem. It detects AVX2, AVX-512, PCLMULQDQ, BMI2, FMA3 and more at run time for RAID, database and AI-inference projects. The downloads are diagnostic tools that report what your CPU supports.
